# SVG 图标编辑器

一个单文件的 SVG 图标制作工具。把几段 SVG 代码拼成一张图标，调好颜色和阴影，导出高清 PNG 或者复制纯净的 SVG 代码。

打开就能用，没有任何依赖和构建步骤。

**在线使用**：https://zoneyottazenith.github.io/svg-icon-studio/

---

## 怎么用

左边粘贴 SVG 代码，右边实时预览。点「图标模式」进入合成模式后，可以继续添加图层。

每个图层就是一段独立的 SVG 代码，不管它内部有多少个 `<g>` 和路径，都当成一个整体处理，不会被拆散。图层之间可以各自调位置、缩放、旋转和不透明度，互不影响。背景是最底层的垫板，整体圆角作用在背景上，所以这两项是全局的。

染色支持保留原色、纯色和渐变三种。染色时直接改写原始元素的 `fill` 和 `stroke`，不用蒙版拍平图形，所以导出后的 SVG 仍然可以逐层改色。阴影是每图层独立的，方向用一个可拖拽的圆盘控制，不限于固定几档。

## 导出和复制

导出 PNG 按长边像素选尺寸（1024 到 8192），走的是矢量重绘而不是位图放大，所以大图依然清晰。没有背景时导出的就是透明底。

复制按钮复制的是剥离了背景和圆角的纯净图标代码，方便直接嵌到别的地方用。预览和导出不受影响，背景该有的还是有。

## 其他

撤销和恢复记录每一步操作，拖滑块产生的连续变化会合并成一步。刷新页面不会丢状态，连撤销历史都保留。深浅色主题跟着系统走，也能手动切。

取色器是自研的，因为浏览器原生的颜色弹窗位置不可控，在滚动的面板里经常被裁掉。

移动端把操作面板收成底部抽屉，预览占大头，面板内部可以上下滑动。
